- 客户所处阶段（销售早期 / 临近决策，天平模型定位）：推断★（依据用户叙述的事件时点）；已观察后果（拖延 / 实施不顺迹象 / 废标重招迹象）：读档 + 直问

### C 组 · 大项目·领先：设置转移成本盘点

### D 组 · 小项目·领先：解除顾虑三正确素材

## 四、工作流（依 `reference\05-信任巩固.md` 执行，工具后标注置信度级别）
> 总原则：**先归因、后分支**。没弄清顾虑是什么就谈策略，等于方法论说的"开处方"。
### 第 1 步 · 疑虑三问（顾虑归因，方法论第一~三节）
- **定义**：客户已基本选定供应商，但对后续合作能否成功表示担心——担心事=项目能否顺利进行；担心人=销售是否靠谱。
- **成因·天平模型**（方法论第二节）：销售早期"不买"侧只放解决成本；临近决策加码"额外费用 + 采购风险 + 解决成本"。大白话："早期客户想'买了有什么好处'；临近签约想'万一你做不到，我要多花钱、担风险、还得重新折腾'——越接近签约越容易犹豫。"据此定位客户所处阶段。
- **后果·三环循环**（方法论第三节）：拖延签约 → 实施不顺 → 废标重招，三环循环、不处理会沿循环恶化。
- **随访观测 · 签前健康度口诀**（三时段逐项观测灯色：签前期 / 签约~首批交付期 / 首批交付后；黄=加密接触+归因复核，红=回第 1 步重归因+按分支升级动作）→ 阈值与观测口径详见 reference\05-查表素材.md 第5节「表五 · 签前健康度信号表」。
- **顾虑表现四选**（定义见 A 组）：逐项与用户核对当前出现哪几种表现——**推迟签约必追"借口是什么、拖了多久"，额外施压必追"具体要求内容"**，这两处是第 2 步推断的原材料。
### 第 2 步 · 顾虑指向推断（担心事 / 担心人）
本 skill 的核心推断字段，走五步推断协议，思考链路全程对用户可见。**方法论锚点**："感性大于理性，或不便表达，便向销售提出额外要求，**往往又不是问题关键**"——客户嘴上提的（借口、额外要求）≠ 真顾虑。默认生成 ≥2 个假设（指向"事" / 指向"人" / 外部触发），逐方向对照典型信号、用区分性验证问题向用户取证（不得凭单一线索定档）→ 三方向假设表（含"定档后动作"第四列，一跳直达分支）详见 reference\05-查表素材.md 第1节「表一 · 顾虑指向推断假设表」。收敛后给结论+置信度（高/中/低），**低置信度不得作为分支策略唯一依据，先转验证**；用户确认后转正落 L4 交互记录（原话+推断+确认状态），用户推翻时记录修正理由。
### 第 3 步 · 第一分支：领先 / 落后（方法论第四节）
**复用商机评估画布的领先/落后定位结论（自检项 3），本 skill 不得重新判断。** 判定后向用户大白话确认："按商机评估的画布记录，这单我们是领先方（客户基本选定我们）/ 落后方（客户倾向还没定或倾向对手），对吧？后面所有动作都按这个分岔走。"

### 领先分支（客户选定我方：发现疑虑 → 解决疑虑）
**先分项目大小**（金额/体量判断，直问确认）→ 大项目走 3A/3B，小项目走 3C/3D，3E 跟进序列跨大小项目通用。
#### 3A · 大项目 · 需求澄清会 + 项目执行预案（方法论第五节）
- **前置闸门 · 客户方项目 owner 确认四问**：能实际参会（不是"被邀请"）/ 能在采购·质量·法务卡点拍板 / 能推动客户内部落地动作 / 卡住时能升级——逐条点名具体人，**任一项点不出人名 → 不进入填表**，先转动作：高层邀约补位，或转决策链破译（02-juece-poyi）补五维地图（缺关键人即侦察任务，不凭空编人）。大白话固定一句："签的是合同，驱动合同的是人——点不出这个人，预案会就是我们对空气讲计划。"→ 四问点名问题与点不出人名的处置详见 reference\05-查表素材.md 第2节「表二前置 · 预案会客户方项目 owner 确认四问」。
- **甘特逐格引导**：按方法论"实施计划总表"五阶段结构逐格引导——**03~05 阶段的我方投入、客户投入与全部"预防与应急方案"行为空=强制询问项**（内容警示见第五节），必须逐格问用户"这个阶段我方要投什么人、做什么事？客户要投什么？可能出什么岔子、出了找谁？"，**不得静默照抄空表交付** → 空表骨架与强制询问口径详见 reference\05-查表素材.md 第3节「表二 · 实施计划总表骨架」。每格配大白话（如"预防与应急那一行，大白话：就是'万一出事的 Plan B 写清楚，别到时候互相甩锅'"）。
- **会中议程**（预案会 30~45 分钟）：开场对齐目标（含"3 个月后什么样算成功"成功定义环节）→ 四模块（讲计划 / 讲配合 / 讲风险与预案 / 讲切换成本）→ 逐模块时长与主持要点详见 reference\05-查表素材.md 第4节「表四 · 项目执行预案会议程」。
- **双 24h 口诀（会前 / 会后两个时点，不可混淆）**：会**前**=中标后 24 小时内发起邀约、一周内召开预案会（另有口径"中标 48h 内拉关键人开澄清会"，两者不同【待核实】，默认按前者执行，向用户确认时点与参会关键人名单）；会**后**=会后 24 小时内向客户发出纪要（共识要点 / 里程碑 / 下次会议时点；此会**后**时点与会**前**邀约是两个不同时点，双口径【待核实】不受影响），落 L4 交互记录。纪要副本作为 **客户经营（06-kehujingying）** 的交接输入（交接四件套之一），写进落档模板（模板三）。
#### 3B · 大项目 · 设置转移成本（方法论第六节）
带用户盘点三环维恩图，逐项问"已存在 / 可强化"：**学习成本**（新产品 / 操作方法 / 新流程）——大白话"客户已经学会用我们的东西了，换别人得从头学"；**交易成本**（可能要换系统 / 配件不通用 / 维修需更多备件）——"换掉我们，他手里的系统、配件、备件全成废铁价"；**机会成本**（不能享受老用户优惠）——"老客户待遇（价格、优先级、资源）只有留下才有"。产出=三成本盘点表，并给"可主动再加固哪一环"的动作建议。
#### 3C · 小项目 · 解除客户顾虑：三正确（方法论第七节）
- **01 增强交流、唤醒感情**：回顾双方共同目标和利益，唤起合作情感，**从而探明疑虑**（目的是探明，不是客套）；
- **02 预演未来、增强信心**：预测实施中可能遇到的问题 → 如何管理 → 还有哪些不放心的（三问逐条过）；
- **03 高管会面、增强信心**：高层出面，展示【待核实：方法论"希纳斯"三字疑为"展示"】对此项目的重视和承诺的有效性。

**施压/借口承接话术**：客户当场要求降价、额外条款/保证或抛"再考虑考虑""要跟领导汇报"类借口时，用四段式话术骨架（承接→探因→回应→转下一步）→ 详见 reference\05-异议话术.md 第1~5节「① 要求降价 ~ ⑤ 翻旧账」（含统一四段式定义、两条硬规则与逐节三错误对照行）。
#### 3D · 小项目 · 三错误（方法论第七节）——**本 skill 的输出校验规则（铁律级）**
- **01 淡化问题**：否定客户关心的问题的重要性，或给出毫无根据的承诺（校验触发词："没事的""不用担心""保证没问题"）；
- **02 开处方**：不明原因的情况下直接建议和主张（归因未完成就输出"你应该给客户……"类建议）；
- **03 施加压力**：用价格、购买期限压力逼客户决策（"再不签就涨价""限时优惠""这个月必须定"）。

**自我否决机制**：产出行动清单前逐项扫描自身输出，含任一模式**必须自我否决并重写**（如把"告知客户本月不签价格作废"改为"先弄清拖延的真实顾虑"）；三错误对照**前移到话术生成时即逐条扫描**（生成承接话术/跟进触点时逐句对照，非产出后补扫）→ 逐节对照行详见 reference\05-异议话术.md 第1~5节各节末「三错误对照」。
#### 3E · 跟进序列（跨大小项目通用；拖延≥7 天或躲避持续即启动）
签前犹豫（拖延/躲避）不是一次判题就结束——客户拖延后**第一次再接触说什么、隔多久、走什么渠道、每次带什么新价值**，按疑虑表现四选各给一条序列（翻盘迹象单独加密序列）→ 序列与触点话术骨架详见 reference\05-跟进序列.md 第2~5节「序列一 ~ 序列四」。硬约束（与三错误平行的"三禁"）：**未过第 2 步归因的，跟进只许探明疑虑、不许夹带逼单**；每次触点必须带新价值（禁"就问下考虑得怎么样了"式空触达）；紧迫感只许用事实（交期、产能、评标节点），不许制造 → 通用参数与逐触点自检清单详见 reference\05-跟进序列.md 第1节「通用参数」与第6节「用法自检」。

#### 4A · 先判断局势：ABCD 表（方法论第八节；**实践口径行为空**）

| 战略价值 | 经济效益 | 级别 | 销售策略 |
|---|---|---|---|
| 大（大客户） | 大（大项目） | A | 适可而止：后续还有大量合作机会，有翻盘则争取，不能翻盘则适可而止，为后续合作打基础 |
| 大 | 小 | B | **⚠ 方法论此格为空——强制确认项，见下** |
| 小 | 大 | C | 殊死一搏：竭尽全力制造和扩大疑虑，力求翻盘 |
| 小 | 小 | D | 潇洒离去：单子很小、没有未来，不值得拼命 |
**实践口径策略 = 强制向用户确认项**（方法论空白，静默跳过视为缺陷）：skill 必须明确问用户——"实践口径（战略价值大×经济效益小）落后时的策略为空白，这单正好是实践口径（或接近实践口径），您倾向哪种打法？是按'适可而止、为后续合作留路'，还是按'殊死一搏'（低置信度备选）？"，并在输出中标注"【实践口径策略为空白，本项为用户决策】"。级别三列（战略价值/经济效益/客户级别）**直接取自商机评估画布，不重判**；另外补问三项方法论表外但实战必需的输入：翻盘可能性、后续合作空间、时间约束（是否临近废标）。
#### 4B · 制造与扩大疑虑（方法论第九节）
- **业务层面（事）**：引导客户关注竞争对手的弱点——尤其后续实施阶段可能出现的问题，埋下不满的种子。素材来源=长期记忆·4 弹药库（竞品差异化要点、历史输赢归因）+ L4；缺素材 → 转缺口侦察任务（去搜集对手实施阶段的黑历史），**不得编造竞品弱点**。
- **组织层面（人）**：**显式引用决策链破译（02-juece-poyi）的五维地图 + 圈子地图**——分析"该项目让其他帮派做，意味着谁控制权的丧失"，找到可撬动的关键人。档案缺失时按第一节自检项 4 降级：问用户要点结论，答不上则标"需先完成决策链破译五维地图"转侦察任务。
- 大白话："事"的层面是让客户的脑子里种下'对手交付可能翻车'的种子；"人"的层面是找客户内部哪个派系最不希望对手上位，帮他把反对对手的理由说出来。
