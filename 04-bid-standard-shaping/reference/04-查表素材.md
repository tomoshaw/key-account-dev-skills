## 一、三局势应对速查

### 1.0 判定树（扫码即判；判定核心=支持者话语权在谁手里；细化策略见 1.3/1.4）

```
评标/立项话语权在谁手里？
├─ 我方支持者 → 流程节点对我方透明？
│   ├─ 是 → 胜利在望（防投诉，走流程）
│   └─ 否 → 难分高下（补透明度，黄灯）
├─ 双方各有人支持 → 客户是否已有标准？
│   ├─ 无 → 难分高下·情形A（建标准）
│   └─ 有/两派相争 → 难分高下·情形B（找关键支点人物）
└─ 竞品支持者占上风 → 翻盘窗口还开着？
    ├─ 关 → 绝处逢生·上策 体面退出
    ├─ 一线机会 → 中策 回决策链破译找未堵死的通道
    └─ 还有愿听你说话的人 → 下策 硬碰硬改标准
```

### 1.1 局势描述（判定输出词表；判定核心=支持者话语权在谁手里）

| 竞争局势 | 局势描述 |
|---|---|
| 胜利在望 | 你的支持者在客户内部获得话语权，基本要选你，但需要走完流程 |
| 难分高下 | 客户对你和竞品无倾向，或内部不同势力分别支持双方，鹿死谁手尚未可知 |
| 绝处逢生 | 竞品支持者在客户内部占据上风，基本已选定竞品，需要走流程 |

### 1.2 应对策略（应当 / 避免；本列为单一内容源，引用时注明出处）

| 竞争局势 | 应当 | 避免 |
|---|---|---|
| 胜利在望 | 能单一来源就不要 PK，尽快推动流程，开标定标 | 标准倾向太明显，让竞品有理由投诉或质疑 |
| 难分高下 | ① 进攻权力型（权力者），争取先机；② 搞定"关键人"，设置有利标准；③ 建立标准，先入为主。细化见 1.3 | 在不利我方的情况下参加招标死磕 |
| 绝处逢生 | 上中下三策见 1.4：体面退出 ＞ 销售流程退档（回决策链破译环节找未堵死的通道）＞ 硬碰硬改标准（走步骤六）。实践口径：① 决策链分析与公关（显式调用决策链五维地图）；② 硬碰硬改标准；③ 体面退出 | 砸巨大资源强行匹配 |

### 1.3 难分高下·拆两情形（内容源第十二节）

- **情形 A 客户尚无标准**：上策用战略价值地图获高层支持、中策用差异化建标准。
- **情形 B 客户内部两派**：识别**关键支点人物**（能影响标准制定的 / 代表业主发言的 / 能影响专家意见的 / 能打破天平平衡的）集中突破。
- **总原则**：**找支点破局，不在不利局面堆资源硬拼**（即便惨胜也会压利润、透支团队）。

### 1.4 绝处逢生·上中下三策（内容源第十二节）

| 策略 | 内容 | 适用前提 |
|---|---|---|
| 上策 体面退出 | 翻盘窗口已关闭，保利润保团队保下局 | 翻盘窗口已关闭 |
| 中策 销售流程退档 | 退回决策链破译阶段找未堵死的通道 | 还存在一线机会 |
| 下策 硬碰硬改标准 | 正面挑战关键条款 | 客户内部还有愿听你说话的人 |

金句："体面退出比惨胜更明智——惨胜可能赢了项目，但输了利润、输了团队、输了后续合作的机会。"

### 1.5 检查点与里程碑（内容源第十二节）

检查点：标准状态判断 → 竞争局势判断 → 标准引导表（软硬区分/重要性/竞争矩阵）→ 标准引导策略（差异化）→ 盟友共识 → 标准落地（有利标准已纳入采购文件或评标细则）。**里程碑**：客户采购标准中包含对我方有利的评估指标；项目进度 80%（参考值）；产出物 = 标准引导方案。

## 二、改标准四方法查表

**适用规则**（正文口诀）：杀手指标 → **反客为主 / 鱼和熊掌**（淡化弥补）；沉睡指标 → **偷梁换柱 / 调虎离山**（逐渐唤醒）。

**编号说明**：引用顺序统一为 反客为主01 / 鱼和熊掌02 / 偷梁换柱03 / 调虎离山04。

### 2.1 反客为主（01，杀手指标）

- **定义**：改变客户原有指标的重要性排序——提高原先排序靠后但对我方有利的指标，降低对我不利的指标。
- **A vs H 动作要点**：H 公司是在位集成商，客户默认排序"技术成熟度 > 系统稳定性 > 价格 > 备件供应 > 智能工厂评定"对其有利；A 公司在**需求调研阶段向生产部提交《存量产线运行风险分析报告》**（核心论点：产线运行多年、备件依赖原厂、平均到货周期超 30 天、停线风险不可控），把"备件供应周期/停线风险管控"拉到需求论证核心位置——**在技术规格书编制之前改变评标权重**。
- **话术方向**："这次改造不是新建，是在不停产条件下换核心部件。建议把'备件供应周期'和'停线风险管控'作为需求论证的核心要素——如果备件周期长，系统稳定性再高，一次故障就可能突破安全底线。"
- **提交对象参考**：生产部（风险分析报告）。

### 2.2 鱼和熊掌（02，杀手指标）

- **定义**：让客户在两个重要指标间取舍——预算撑不起全部期望时，引导保留对我方有利的标准、放弃对我不利的。
- **A vs H 动作要点**：抓住客户内部"生产部要技术最先进 vs 财务部要预算可控"的矛盾，给客户两个方向做选择题（方向一全新架构高投入 / 方向二兼容现有设施+核心部件国产替代、不停产、投资可控），把决策逻辑从"比谁最先进"引导到"**预算约束下谁的改造影响最小**"——A 公司的优势战场。
- **话术方向**："方向一'技术最先进'，采用全新架构，但需要更换前端设备，投资较高。方向二'兼容现有设施、核心部件国产替代'，不停产改造，投资可控。如果预算有限，建议优先考虑方向二——把钱花在核心部件上，改造期间对生产影响最小。"
- **提交对象参考**：财务部/决策层（方向取舍论证）。
- **呈现规则**（本 skill 生成）：
  1. **先问现状再抛方向**——抛方向取舍前先问"这次改造的预算口径是什么？改造窗口有没有停产红线？"；让客户自己说出约束，方向二（我方优势方向）才显得是"他自己算出来的"，不是我们塞给他的。
  2. **备选方向必须真实可执行**——两个方向都必须是我方真实可交付的方案，不拿我方也做不到的"方向三"凑数；每条方向给出取舍逻辑与预算量级。客户拿计算器复核时唬弄不过去的，宁可不抛。

### 2.3 偷梁换柱（03，沉睡指标）

- **定义**：对客户原有指标重新定义，通过定义的改变改变标准。
- **A vs H 动作要点**：原标准"系统可用率≥99.5%"对 H 有利（存量数据稳定）；A 公司**向信息部提出**把可用率重新定义为"**包含备件供应周期在内的综合可用率**"——同一指标定义一变，H 的存量数据优势被削弱，A 的备件周期优势被固化进技术规格书。
- **话术方向**："99.5% 的可用率，是在备件正常供应前提下的统计。如果备件到货周期是 30 天，一次核心部件故障导致的停运时间就可能超过 0.5%。建议把'系统可用率'重新定义为'包含备件供应周期在内的综合可用率'。"
- **提交对象参考**：信息部（指标重新定义建议）。

### 2.4 调虎离山（04，沉睡指标）

- **定义**：用全新解决方案满足客户需求，使客户原定的标准和方案整体被替换。
- **A vs H 动作要点**：原方案"在现有产线上局部改造"对 H 有利（其掌握系统接口）；A 公司**向工厂提出**"产线集成+数据驱动"新平台方案（兼容现有产线、不停产施工、驻场保障，并为智能工厂评定与海外工厂复制预留接口）——客户关注点从"要不要换供应商"变成"要不要借机会做架构升级"，原技术规格书需重写，H 的存量优势被绕开。
- **提交对象参考**：工厂管理层（新方案框架）。
- **交付红线**（本 skill 生成）：新方案必须真实可交付——方案里每一项承诺都要能在我方交付记录里找到对应案例，否则是给自己挖坑（中标后交付不了，比不改标准输得更难看）。

### 2.5 开工闸门 Checklist（步骤六前置；四项全勾才输出改标准动作，**任一未勾只输出侦察任务，不出动作品**）

- □ 标准话语权持有者已从决策链五维地图定位（或已明示按降级推断处理）；
- □ 窗口未关：技术规格书/评标办法定稿时间已知，且本动作时点在其之前；
- □ 弹药就位：本动作引用的报告/案例/实测数据已在记忆·4 或本次临时采集，逐条标注来源；
- □ 局势与象限一致：目标指标确属杀手/沉睡指标（非优势/可放弃指标）。

（五步推断协议本体见 SKILL.md 第六节 6.1，此处只放字段查表。）

| 字段 | 典型用户原话 | 推断依据（内容源锚点，标注置信度） | 区分性验证问题 |
|---|---|---|---|
| **局势判定**（胜利在望/难分高下/绝处逢生） | "客户老总基本定了我们，但还得走流程" / "感觉客户谁也没倾向" / "他们内部两派在争" | 内容源 5.1 局势描述：**判定核心=支持者话语权在谁手里**（高置信度，需决策链五维地图佐证话语权）；结合商机评估九宫格开局倾向映射三局势（确认口径锚点） | ①支持我们的那位在评标/立项环节说话算数吗？话语权体现在哪个节点？②客户对双方的接触动作对等吗（都约见/只单方/只给对手看细节）？③客户是否已清楚下一步并按流程推进、且流程节点对我方透明？ |
| 客户倾向状态（局势判定输入） | "客户没说选谁，但老问我们细节" | 商机评估开局倾向定义：开局领先=客户倾向明显；动作不对等=倾向信号（确认口径） | 客户对双方的动作是否对等？条件是不是只拿给单方问？ |
| 竞品支持者是否占上风（局势判定输入） | "听说他们技术处已经定了对手" | 内容源 5.1"绝处逢生=竞品支持者占据上风"；须决策链破译派系与五维地图佐证（实践口径，传闻须标可信度，并过第三节竞品情报证据纪律） | 消息来源是谁？是评标相关角色吗？同一信息另一派系的人认不认？ |
| **指标软硬属性** | "标书里写'服务要好'" | 内容源第 6 节：硬性=可量化（价格/设备参数/技术指标/交货时间）；软性=难量化（品质稳定/口碑信誉/服务水平/道德规范）（确认口径） | 这个指标有没有可写进招标文件的量化口径/验收数值？没有的话，谁说了算它"好不好"？ |

**竞品情报证据纪律（三条；任一违反，该情报降级为线索，不作竞争矩阵与局势判定依据）**

1. **竞品能力对比须标"截至日期"**（如"截至 2026-10"）——过期情报只作线索，不作依据；
2. **"标书/官网未见"≠竞品做不到**——只证明该文件没有这项内容，不证明竞品没有这个能力；
3. **动机推断与事实分离**——"竞品为什么这么做"属动机推断，单独标注"动机推断"，不写入竞争矩阵依据链。

## 四、改标准攻防话术（五件套库）

> **定位**：改标准动作清单给出"向谁提交什么材料"，本节回答"提交之后被反问、被堵、被告状时怎么说"。**本话术库由本 skill 生成**，供现场适配使用；话术中的 [方括号] 为占位符，执行前必须替换为客户真实数据——真实数字是话术可信度的全部来源。

### 使用规则（先看这个）

- **双框架骨架**：每条话术按 FFR（认同—同类案例—具体结果）或 ABC（认同—重构—证据+下一步）组织；先认同再重构，**禁用"但是"开头**，改用"同时""换个角度"。
- **时长**：每条逐字话术控制在 15–25 秒口语长度（约 40–90 字），念不完就删。
- **五件套结构**：① 反制场景 → ② 客户这句话的真实含义 → ③ 逐字应答话术 → ④ 追问句 → ⑤ 红线（何时停止该动作）。
- **红线通则**（任一触发即停）：客户两次明确拒绝该方向；内线传话"别再提这件事"；竞品已就此事向客户告状且客户态度转冷。停止后回查步骤五局势判定与健康度，不硬冲。

### 4.1 反客为主（01，杀手指标）

**反制场景①：客户技术处/评标口径制定人质疑"为什么这次突然要评备件供应周期？以前从来没评过这个。"**

- ② 真实含义：不是说指标错，是担心被看出"照着你方利益加指标"，更怕程序上被竞品投诉"量身定制"。
- ③ 应答（FFR）："您这个顾虑很正常。我们服务的 [某同类工厂] 三年前也只评成熟度和稳定性，后来一次核心部件故障，备件等了 30 天，停线损失 [X] 万元。他们现在把备件周期写进了评标办法，这两年没再停过线。这个指标不是我们发明的，是同行拿停线换来的教训。"
- ④ 追问："您看现在产线上核心部件的备件库存，真出故障能撑几天？"
- ⑤ 红线：客户明说"这个指标提得太巧了，你们是不是照着对自己有利写的"，且不接受"同行先例"解释 → 停止加指标动作，转用鱼和熊掌的预算约束路径重新论证，不恋战。

**反制场景②：内线传话被堵——"生产部说最近不方便再碰需求调研的事。"**

- ② 真实含义：内线被上级提醒避嫌，或竞品已递话施压；也可能只是临近程序启动、时点敏感。
- ③ 应答（ABC）："理解，最近时点上确实敏感。这样，这份《存量产线运行风险分析报告》我们不以'评标建议'的名义送，只作为产线运维台账送给生产部做日常参考，内容一字不改。等需求论证会开起来，他们手里正好有这套数据。"
- ④ 追问："生产部是被提醒避嫌了，还是单纯排不开时间？这两条解法不一样。"
- ⑤ 红线：内线明确说"对方已经盯上这份报告了" → 暂停私下纸质递交，改走客户内部正式渠道（技术交流会议题申报、专家评审会材料），不留"私下塞材料"的口实。

### 4.2 鱼和熊掌（02，杀手指标）

**反制场景①：生产部反问"你们是不是想让我们选便宜的方案？技术先进性到底好在哪，你说不清楚就别谈了。"**

- ② 真实含义：生产部（可能是技术派或亲竞品方）怕我方拿预算牌压技术路线；真正的软肋是"别让我背技术倒退的责任"。
- ③ 应答（ABC）："技术先进确实是方向一的核心价值，这一点我不回避。同时我们把两笔账都算清楚了：方向一全新架构要更换前端设备，停产窗口约 [X] 天，产线损失约 [Y] 万元；方向二不停产，核心部件投资 [Z] 万元。这是两份测算的底表，哪一笔您不认，我们当场核。"
- ④ 追问："如果走方向一，停产窗口的损失这笔账，到时候算在哪个部门头上？"
- ⑤ 红线：两个方向里有任何一个我方真实交付不了 → 不抛该方向，先回解决方案设计环节补弹药再约；鱼和熊掌成立的前提是"熊掌也是我方能兑现的"。

**反制场景②：财务部质疑"两个方向都是你们的产品，说到底就是想多赚钱。"**

- ② 真实含义：客户警惕"选择题是销售套路"——选项都是我方的东西，选哪个我方都赢。
- ③ 应答（FFR）："财务这么问非常专业，很多供应商确实拿选择题当套路。我们的两份测算用的是同一套造价模型，方向二我们的毛利反而更低——但停线风险小，贵部门预算的执行风险也小。账都在表里，哪一笔不认都可以当场划掉。"
- ④ 追问："这次改造的预算口径，是投资总额卡死，还是年度支出卡死？口径不同，最优解不一样。"
- ⑤ 红线：取舍逻辑经不起财务部拿计算器复核 → 当场撤回方向呈现，补齐测算证据后再约，不硬撑。

### 4.3 偷梁换柱（03，沉睡指标）

**反制场景①：信息部/技术处质疑"可用率定义一改，跟历史数据还对得上吗？审计怎么解释？"**

- ② 真实含义：担心重新定义让历史对标失效，内部要有人为口径变化背责任。
- ③ 应答（FFR）："这个担心有道理。行业里最怕的是指标名不变、口径悄悄变，那才真说不清。所以我们建议原指标保留、历史数据照常对账，新增'综合可用率（含备件供应周期）'从本期开始单独统计。审计看到的是口径更细，不是口径被改。"
- ④ 追问："现在这套系统里，备件到货周期能自动统计出来吗？还是要靠人工台账？"
- ⑤ 红线：客户只接受"旧定义评标、新定义参考" → 接受半胜，不再纠缠；转而把新定义争取写进运维考核指标，换一条路径固化。

**反制场景②：竞品向客户告状"他们在改指标定义，就是要废掉 H 公司的存量数据优势。"**

- ② 真实含义：客户已经把告状当回事；此时急着辩解=坐实"确实是针对 H"。
- ③ 应答（ABC）："这话传到我耳朵里，我不意外。指标该不该包含备件周期，跟谁来投标没有关系——就算 H 公司来投，备件 30 天到货的风险也一分不少。这样，我们把论证写成一份中立的《指标口径技术白皮书》，请双方都来提意见，谁的意见有数据支撑就采纳谁的。"
- ④ 追问："告状这件事，是哪位跟您说的？他希望我们怎么回应？"
- ⑤ 红线：客户态度明显被竞品叙事带走（"你们两家打，别在我这里打"）→ 停止白皮书动作，退回"运维建议"层面等局势回稳，先查步骤五健康度。

### 4.4 调虎离山（04，沉睡指标）

**反制场景①：客户管理层质疑"上平台是不是大跃进？我们就想修个设备，别搞成 IT 项目。"**

- ② 真实含义：怕"数字化转型"帽子绑架预算，怕项目复杂化后自己担责。
- ③ 应答（ABC）："您这个判断非常务实。这次改造的核心仍然是核心部件替换，数据平台层是随改造顺带搭的骨架，不新增预算项；将来用不用、什么时候用，主动权全在贵方。"
- ④ 追问："贵方后面有没有智能工厂评定或者新产线复制的计划？哪怕只在内部讨论过。"
- ⑤ 红线：客户明确"我们只谈部件更换" → 收缩方案，只保留"兼容现有产线、不停产施工"两个真实差异点，平台叙事全部收回；新方案任何一项我方交付不了的，从一开始就不许写进方案（见第二节 2.4 交付红线）。

## 五、健康度红绿黄（攻防是数周过程，判定不是一次定档；每次交互刷新一次）

口诀：**"窗口过半、人心变了、对手动了——三个信号亮一个，先复核再动作"**

- 🟢 **绿灯**：窗口未过半 + 支点人物态度未变 + 竞品未察觉 → 按既定策略推进；
- 🟡 **黄灯**：任一项存疑（如支点人物连续两次未兑现承诺动作）→ 触发复核：重查决策链五维地图的话语权格局，再决定继续投入还是收缩；
- 🔴 **红灯**：窗口关闭（标书定稿/已开标）或竞品已察觉并反制进入评标程序 → 按绝处逢生三策重新定档，不恋战。

## 六、运行示例（练手对表）

**用户**："标书里的技术参数一看就是照着对批注的，技术规格书下周定稿。"

**skill 处理链路**：

1. **步骤一**：三判断——客户清楚下一步（开标）、议题只谈具体条件（窄）→ 判定【已有且偏向竞品】，证据两条注明；
2. **步骤五**：查决策链五维地图无档 → 输出开头明示降级模式，按用户口述"技术处认可我们、但处长倾向对手"走五步推断 → 判【难分高下】、置信度中，健康度标黄灯（流程节点透明度存疑），并提醒"建议先跑决策链破译环节把话语权坐实"；
3. **步骤二~四**：把标书参数逐条分软硬、排重要性、落竞争矩阵 → 找出杀手指标（如"系统可用率存量数据"）与沉睡指标（如"备件供应周期"），竞品强弱结论逐条标"来源+截至日期"；
4. **步骤六**：先过开工闸门（话语权已按口述降级定位、窗口=技术规格书下周定稿、弹药需用户确认）→ 杀手指标用反客为主/鱼和熊掌、沉睡指标用偷梁换柱/调虎离山，每个动作落到"向谁提交什么材料"（见第二节「改标准四方法查表」），弹药逐条标注"依据公司记忆·4"，时点全部压在技术规格书定稿之前；每个动作预判一个最可能反制并备应答——如向生产部递《存量产线运行风险分析报告》后，最可能反制是技术处质疑"为什么突然加备件指标"，按攻防话术 4.1 场景①的 FFR 话术准备（数字须先用真实数据替换）；
5. **输出**：局势判定结论先行 + 竞争矩阵 + 改标准动作清单，末尾落档回显路径，缺口（处长立场、预算口径）转侦察任务登记 L5。

*要点：上游缺什么就明示降级模式、不中断；每个判断配大白话；应对策略注明单一内容源出处。*
