## 五、决策树（树体，判定细节仍以 SKILL.md 对应步骤规则为准）

**树 A「先修体验还是先谈新需求？」**——步骤 1 落档后、进步骤 4/5 之前必走：

```
满意度档位 = 悔不当初？
├─ 是 → 先补救止损：新需求开发降级为"重建信任"，不进步骤 4/5
└─ 否 → 白费力气？
    ├─ 是 → 先修复体验（响应与沟通补课），修复见效后再谈新需求
    └─ 否（皆大欢喜／还好是你）→ 过闸门 F2，进步骤 4/5 开发新需求
```

**树 B「关键人变了，先走哪条线？」**——场景 F3 命中后必走：

```
变动者是原决策者／权力层？
├─ 是 → 移交 `02-juece-poyi` 破译新决策链，破译后回 `06-kehujingying` 做经营衔接
└─ 否 → 仅执行层变动？
    ├─ 是 → 过闸门 F3，走步骤 5·组织线 Option 03：新关键人及时见
    └─ 否（无人事变动）→ 维持现状，仅更新 L1/L2 人物画像
```

## 八、运行示例（五步推断协议应用示例）

### 8.1 心理阶段推断展示示例

> 观察点："上线一个月，天天投诉"→交付初期、问题密集。假设 A：磨合期（依据：方法论"任何产品交付难免出问题，客户积极性下降"，与"上线一个月+问题密集"吻合）；假设 B：悔不当初（依据：若目标也未达成则跌入该档，需排除）。区分性验证问题："当初约定的上线目标都达到了吗？客户现在还愿意坐下来跟你们一起解决问题吗？"→ 若目标达成、客户仍配合=磨合期（置信度高）；若目标未达成且客户拒绝沟通=悔不当初（置信度中，需先补救再谈其他）。
