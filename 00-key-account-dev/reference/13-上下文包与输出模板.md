## 五、archive\_index 摘要生成规则（单一权威源）

上下文包 `archive_index` 字段的完整生成规则在此定义，SKILL.md 只留指针：

- **来源**：按共享协议第六节供给优先级，从当前供给通道（记忆工具 / CRM 等业务系统 / 工作区参考文件）读取客户档案各层的**头部与结论段**，不整册搬运；
- **每层 ≤10 行**：
  - L1 摘组织架构层级数/人数/决策机制是否摸清；
  - L2 只列"姓名-职务(角色,五维关键档,画像版本日期)"，一行一人；
  - L3 只列"项目名: 已完成环节+日期"；
  - L4 只列最近 3 条交互的一句话；
  - L5 列开放状态缺口编号与标题；
- **指针原则**：摘要里出现任何结论，同时给出档案条目定位（工作区相对路径或系统记录 ID），供 skill **按需深入**读取全册；摘要本身不得包含画像细节全文、交互记录全文；
- 档案不存在时 `archive_index` 各层为 `null`，由阶段 skill 自行采集建档。

## 六、体检健康度红绿灯（时间维度，G3 定期体检必附）

静态逐项排查（第二节）之外，G3 定期体检与 G1 复盘报告必须加判一项**时间维度健康度**，用红绿灯标注：

| 灯 | 判定（默认示例阈值） | 大白话处置建议 |
| --- | --- | --- |
| 🟢 绿灯 | 近两次交互客户方承诺动作均兑现 | 关系在轨，按原计划推进，别加戏 |
| 🟡 黄灯 | 客户方一次未兑现承诺动作，或关键人一周无回应 | 别催单，先轻触点一下：发条进展同步或请教类消息，试探水温 |
| 🔴 红灯 | 连续两次未兑现承诺，或关键决策节点（截标、评审）前两周无实质推进 | 大概率要凉：降级预期、盘点还有哪个关键人可触达，必要时启动丢单预案 |

说明：上表阈值为**默认示例**，只做三态标注用（与参数三态标注纪律一致）；企业可在记忆里覆盖为自家口径。判不出（无时间线数据）时标"信息不足"，不硬判。
