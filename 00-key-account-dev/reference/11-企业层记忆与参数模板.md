# 11 · 企业层记忆与参数模板

> **定位**：企业层长期记忆（每次会话加载重申）的**唯一权威定义**。供全部家族 skill 引用。
>
> **总原则**：跨项目通用的内部策略、公司要求、行业特点、我方资产 → 长期记忆；客户/项目特异的 → 客户档案（见 `12-客户档案模型与模板.md`）。**一个事实只存一处**。

---

## 一、企业层记忆 5 组

### 1. 评估参数

| 参数 | 方法论资料示例值 | 说明 |
| --- | --- | --- |
| 价值评分维度权重 | 经济效益 40% + 战略价值 60% | 示例，必须用企业实际值替换 |
| 维度内指标权重 | 各 50% | 同上 |
| 业务金额/毛利率阈值 | 5000万+/…；30%+/… | 原注"仅作示例参考，可结合企业业务体量调整" |
| 公司关注方向 | 自由文本 | 参与评分解释（如"优先回款好的项目"） |

**警示**：示例值 40/60 曾被误当企业设定（已有用户纠正过的先例）。备选口径为另一组示例 50%+50%（金额30／毛利20／采购潜力25／标杆25，并细分出 A-/B+ 等级）——两组数值都属**示例**，企业的实际权重/阈值无固定比例，按公司关注方向设定，所有评分输出必须三态标注参数来源（记忆／本次临时／默认示例）。

### 2. 公司策略与要求

- **客户分层资源策略**：A/B/C/D 级打法框架（A级全力拿下设壁垒／B级不鸣则已一鸣惊人／C级一锤子生意／D级挑肥拣瘦）+ **公司实际资源约束**（可投入资源上限、什么级别项目需要管理层审批、投标决策流程）；
- **商务规则**：报价底线与审批权限、账期/付款条件底线、免费 POC/健康检查类投入的审批要求；
- **销售管理要求**：公司明文规定的销售动作（CRM 填报、例会汇报等制度，由用户提供后记忆）。

### 3. 行业特点

所属行业与细分赛道、行业通用采购特征（招标惯例、决策周期、技术评审权重惯例）、关键成功要素、政策环境、周期性。来源：用户一次性提供，或 skill 归纳后经用户确认写入。

### 4. 我方资产（弹药库）

- **三种价值盘点**：产品价值（优势/性能/量化指标）、公司价值（品牌/资质/业绩/专家团队）、销售价值（行业理解与顾问能力）；
- **弹药库要点**：成功案例要点（行业+效果数据）、可引用报告/材料、与主要竞品的差异化要点；
- **商务参数**：成本底线与报价空间规则；
- **关系资源**：我方高层与客户方领导的私人关系、可出面高管名单及承诺权限；
- **机动资源**：技术专家驻场、POC 排期、跨部门攻坚团队的申请通道。

### 5. 输出与协作偏好（已固化，无需用户填写）

每维度配大白话／评分标注参数来源（三态）／行动建议落到"谁、做什么、什么时候"／每个 skill 收尾做贯穿三问复核。

## 三、工作区降级格式：`企业参数.md`

无记忆通道时，在工作区建 `企业参数.md`，内容 = 上述 5 组的 YAML/Markdown 表述，头部注明：

```markdown
# 企业参数（工作区降级存储）
# 本环境未启用记忆通道；若启用长期记忆，以记忆为准，本文件仅作备份。
# 最近更新：YYYY-MM-DD
```

## 四、归属判定速查（一条信息进来存哪）

1. **换个项目还成立吗？** 成立 → 本记忆（第 2、3，4 组）；不成立 → 客户档案；
2. **客户的事实还是我方的事实？** 客户侧（谁、立场、组织架构）→ 档案 L1/L2/L4；我方侧（资源、底线）→ 记忆第 4 组；
3. **结论还是流水？** 过程性事件 → L4 交互记录；沉淀结论 → L2 或记忆。

**常见易重复项**：竞品差异化要点→记忆·4（项目档案只放本项目竞品动向指针）；我方高层与客户领导关系→记忆·4（L2 只标一句话指针）；报价底线→记忆·4（项目档案记"本项目实际报价与审批过程"）；行业采购惯例→记忆·3；客户高层 KPI→档案 L1（解决方案设计的价值地图引用时标"来源 L1"，不复制）。
