# 00 - 方法论总览与方法论框架

> **模块概述**：本模块为方法论"开启篇"，交代大客户营销的底层逻辑——以"道"（布局谋篇，定义赢的逻辑）与"术"（战术执行，保障赢的执行）为总纲，指出三大常见误区，给出供应商与大客户合作关系的三个层级，回顾销售方法论的演变（专业销售技巧→顾问式销售 SPIN→解决方案销售），并以"客户采购流程 vs 我方销售流程"对照表和六阶段流程图（商机评估→客户经营）给出全方法论框架。

---

## 一、大客户营销的道与术

大客户营销由"道"与"术"两个环形环节首尾相接、循环推进：上层为"营销策略"，下层为"高效拜访"。

**布局谋篇"道"：定义赢的逻辑**

- 定义：大客户的开发与经营、销售项目的全生命周期管理，定战略、策略与方向
- 解决问题：赢单靠运气、搞不定高层决策链、陷入价格战
- 目的：提升项目控盘能力、从"跟单"到"控单"

**战术执行"术"：保障赢的执行**

- 定义：执行层、管理层、决策层决策链的拜访能力，定战术，技巧
- 解决问题：拜访效率低、关系难突破、见不到决策人、需求挖不深
- 目的：将策略意图转化为有效的战术推进

---

## 二、大客户营销的三大误区

三大误区：

1. **闻单而动，打法单一**
2. **希望靠一个人拿下业务**
3. **做业务主要靠关系**

**〔演练补充要点（置信度低，不作判定依据）〕**

- "规划：确认项目目标、【待核实：赚钱或搞等／赚钱或投标等】"
- "闻单而动，打法单一"注记：【待核实："光响应需求不行"首字或为"只"】响应需求不行
- "希望靠一个人拿下业务"注记："只搞定领导不行／只在中基层～"
- "大项目：【待核实：重点项目／重点细目】／金额大／采购层级大／不同派系博弈"

## 三、与大客户业务合作关系

供应商与大客户的合作关系沿两个维度递进：

- 纵轴：供应商的承诺与投入
- 横轴：客户的价值预期与投入

三个递进的合作层级（由低到高）：

| 层级 | 定位 |
|---|---|
| 第一层（最低） | 关系型销售／产品供应商 |
| 第二层（中间） | 解决问题/提升绩效／业务伙伴 |
| 第三层（最高） | 支撑战略/战略变革／战略伙伴 |

**〔演练补充要点（置信度低，不作判定依据）〕**

- 战略伙伴层注记："引导需求、目标"
- 第一、二层之间注记："懂业务、挖【待核实：疑为"掘"或"需"】"

| 顾问式销售 | SPIN Selling | 以客户为中心，需求为导向 |
| 解决方案销售 | The Solution Selling | 价值博弈 |

**〔演练补充要点（置信度低，不作判定依据）〕**

两条流程注记：

- 【待核实：首字不清，疑为"客户/总部"】采购流程：
 公司战略 → 立项 → 预算 → 【待核实：疑为"落实了"】责任人确定 → 采购 → {需求确认／技术要求／目标价} → 立项招标 → 采购审批

## 五、客户采购流程与我方销售流程（对照表）

6 列与我方销售流程六阶段一一对应。采购流程行共 4 个阶段标签，"确认需求"横跨前两列，"标准引导"列下方为空白（该节点以阶段标志"基本选定供应商"表示）：

| 行＼销售流程六阶段 | 商机评估 | 决策链破译 | 解决方案设计 | 标准引导 | 巩固信任 | 客户经营 |
|---|---|---|---|---|---|---|
| **阶段标志** | 客户认为问题严重到要解决，需要立刻采取行动（横跨前三列） | 〃 | 〃 | 客户已经有明显的采购标准，基本选定供应商 | 客户做出购买决策，与供应商签约 | 产生新的需求及不满 |
| **客户问题** | ● 我们有什么问题？<br>● 问题够大、够严重、够急迫吗？<br>● 解决问题利益是什么？<br>● 解决问题的代价有多大？（横跨前两列） | 〃 | ● 什么样的标准可以帮助我成功？<br>● 哪个供应商是最佳选择？ | （空白） | ● 可能会有什么风险？<br>● 如果出现问题会产生什么后果？<br>● 这些人值得信任吗？ | ● 能否达到预期效果？<br>● 什么时候能看到效果？ |
| **采购流程** | 确认需求（横跨前两列） | 〃 | 评估方案 | （空白） | 评估风险 | 实施交付 |
| **销售动作** | ● 收集项目信息<br>● 合理运用资源<br>● 制定竞争策略 | ● 发展盟友，共同推进项目<br>● 洞察政治生态，分析决策结构<br>● 深化客户关系，定位主攻方向公关 | ● 深入发现问题，扩大问题<br>● 分析需求，呈现方案，促成决策 | ● 根据客户需求建立标准，匹配标准<br>● 改变或影响对我方不利标准 | ● 领先时主动发现顾虑，消除顾虑<br>● 落后时扩大隐患，想办法翻盘 | ● 有效参与项目交付与管理<br>● 积极开发新需求 |
| **常见错误** | ● 见单就接<br>● 每单付出同样努力与资源 | ● 贸然进入，踩到政治地雷 | ● 未了解客户需求背后的问题<br>● 过早展示方案 | ● 未分析竞争局势，砸资源，强行匹配 | ● 忽视客户顾虑<br>● 施加购买压力促使客户决策 | ● 认为生意已结束<br>● 转移精力 |

**说明**：

1. 采购流程行共 4 个标签（确认需求／评估方案／评估风险／实施交付），"确认需求"对应前两列（商机评估＋决策链破译），"评估方案"对应解决方案设计列，"标准引导"列采购流程为空白，"评估风险"对应巩固信任列，"实施交付"对应客户经营列。
2. **"基本选定供应商"不是采购流程行的标签，而是"标准引导"列的阶段标志**（客户已经有明显的采购标准，基本选定供应商）。按采购流程五段理解：确认需求 → 评估方案 → **基本选定供应商（阶段标志，我方对应阶段为标准引导）** → 评估风险 → 实施交付。**"标准引导"是我方销售流程独有的阶段，不属于客户采购流程**。
3. 【待核实】另一种口径将客户采购流程列为 **6 段**：需求确认 → 方案征集 → 邀标/发标 → 投标/评标 → 定标 → 签约（另有版本为：标前/发标/投标/评标/定标/合同）。与本表"4 标签五段"口径不同，采购流程分段方式**以专家确认为准**；判题使用时两种口径都不影响"我方六阶段"定位。

## 六、方法论要点对照与确认口径

### 6.1 六阶段递进关系（确认口径）

- 阶段一 商机评估——解决"值不值得打"（判断项目价值，决定是否投入资源）
- 阶段二 决策链破译——解决"内部怎么攻"（谁说了算、谁支持谁、怎么切入）
- 阶段三 解决方案设计——解决"拿什么去打"（把理解和诉求转化为差异化方案）
- 阶段四 标准引导——解决"标准对我有利"（把我方优势指标写入采购标准）
- 阶段五 信任巩固——解决"如何顺利签约"（消除顾虑，防止最后一刻翻盘）
- 阶段六 客户经营——解决"如何持续合作"（交付满意，把一单变成持续合作）

**前一阶段产出物是后一阶段的输入，不可跳步、不可逆序。**

### 6.2 里程碑与项目进度

| 阶段 | 里程碑 | 项目进度（参考值） |
|---|---|---|
| 1 商机评估 | 完成立项决策评审 | 10% |
| 2 决策链破译 | 完成决策链地图绘制，发展盟友，形成攻坚策略 | 30% |
| 3 解决方案设计 | 完成方案设计，获不满者与权力者双重认可，确立差异化优势 | 70% |
| 4 标准引导 | 客户采购标准中包含对我方有利的评估指标 | 80% |
| 5 信任巩固 | 正式签订合同 | 90% |
| 6 客户经营 | 账款回收，客户满意，明确后续合作方向 | 100% |

### 6.3 口径差异与采用建议（使用注意）

| 事项 | 口径 | 采用 |
|---|---|---|
| 价值评分权重 | 示例口径一：经济效益 40%＋战略价值 60%；示例口径二：**经济效益 50%＋战略价值 50%**（金额 30%＋毛利 20%＋后续采购潜力 25%＋标杆示范 25%） | 以企业实际设定为准；两组数值都属"示例"（见商机评估模块） |
| C/D 级定义 | 口径一：C级=机会客户·选择性投入／D级=观察客户·暂缓或放弃；口径二：C级=一锤子买卖·利润优先／D级=机会客户·有限投入 | 两种口径不一致，【待核实】以专家确认为准 |
| 客户心理时期 | 四阶段：兴奋期→磨合期→收效期→**拓展期** | 采用四阶段（见客户经营模块） |
| 竞争局势 | 三局势：胜利在望／难分高下／绝处逢生 | 一致（见标准引导模块） |

## 七、六阶段销售流程图（商机评估 → 客户经营）

六阶段流程按 6 个编号模块组织，流程自左向右、自下而上推进：

**商机评估**（顺序执行）

1. 获取项目基础信息
2. 发展接纳型内线接触，进一步收集信息
3. 客户定位，匹配对应资源
4. 项目定位，制定竞争策略
→ 进入决策链分析

**决策链分析**（顺序执行）

1. 设计切入路径
2. 寻找不满者
3. 发展为我方盟友
4. 分析决策结构
5. 确认主攻方向
→ 菱形判断：获得关键人物支持 →（是）长箭头向右进入标准引导"客户方案评估"

**解决方案设计**（顺序执行）

1. 分析职能部门需求
2. 分析高管需求
3. 设计整体解决方案
4. 呈现方案价值
→ 箭头汇入菱形"获得关键人物支持"

**标准引导**（带分支判断）

- 客户方案评估（是否有标准 ST）
 - 否 → 树立标准 →（虚线回路，回到本模块）
 - 是 → 标准对我方有利
 - 否 → 改变标准 →（斜向箭头回到"推动决策"）
 - 是 → 推动决策 → 进入信任巩固

**信任巩固**（带分支判断）

- 菱形判断：客户初步选定我方
 - 否 → 制造顾虑 →（向下箭头经虚线回路退回标准引导"推动决策"一带）
 - 是（向上）→ 解决疑虑 → 控制期望（菱形）
- 控制期望 →（向左箭头）"出现问题"；同时自下方"实施交付"有向上箭头汇入"控制期望"

**客户经营**（闭环）

- 出现问题 —是→ 解决问题（箭头向左回到"出现问题"左侧形成闭环）
- 出现问题 —否→ 展示成果 → 客户满意
- 客户满意 → 开发新需求（箭头向左）；客户满意 ——→ 合作签约（向右长箭头）
- 合作签约 → 实施交付 → 控制期望（自下而上逐级箭头，与信任巩固模块衔接）

**说明**：客户经营模块中各箭头交叉较多，"控制期望"与"出现问题"之间的箭头方向、"制造顾虑"回路的具体落点以斜线/虚线表示，箭头方向按图中可见走向描述，个别连线走向【待核实】。
