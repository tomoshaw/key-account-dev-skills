## 示例 1：一句话进场 → 判题 → 移交主权（正向流程）

**用户**："听说 S 集团下面一个厂要改造产线，预算千把万，我在纠结要不要投精力进去。"

**Gateway 首轮输出**：

```markdown
**我的判断**：您的问题是【刚听到风声要不要跟】，项目现在处在【商机评估】阶段
（大白话：客户自己也还在琢磨"这事够不够大、值不值得动"，咱们比对手早半步，正是定打法的窗口）。

**这次分析我会用到的公司设定**：实践口径客户策略"投入优势资源做好单个项目"（依据公司策略记忆）。

**信息缺口清单**：
| # | 缺什么 | 为什么需要 | 建议找谁问 |
|---|--------|-----------|-----------|
| 1 | 预算是否确为千万级 | 金额决定客户分级与投入上限 | 内线/公开招标信息 |
| 2 | 决策人是谁 | 关系到下一步见谁 | 客户设备科 |

**下一步**：我建议请"商机评估"环节来接，它会带您对项目打分、定打法。确认后我们开始。
（开始前先确认评分参数——您公司评分权重怎么定？先用示例也可以。）
（提醒：这个阶段最容易犯的错是见单就接——先打分再决定投入。）
```

**用户确认后**：移交商机评估（01-opportunity-assessment），注入上下文包——`customer="S集团-某工厂"（归属待确认）`、`scenario="A1"`、`stage_estimate="采购·确认需求期"`、`entities.amount="千万级（传闻）"`、`memory.params_status` 依用户回答落定。

*要点：先判题与缺口、再确认、后移交；记忆项重申放最前；参数询问放在移交话术里，不单独开轮。*

## 示例 2：G1 丢单复盘（本 skill 直接执行的反向体检）

**用户**："Q 厂数字化改造这单丢了，客户最后选了对手，帮我看看输在哪。"

**Gateway 输出（节选）**：

```markdown
**我的判断**：这是【丢单复盘】（场景 G1），由我直接做反向体检——从交付往前倒着查。

**逐项排查表**（六阶段倒序）：
| 排查项 | 判定 | 大白话 |
|--------|------|--------|
| 六 生意是否被当成已结束、交付期断了联系 | 未见证据 | …… |
| 五 是否逼过单/忽视过签前顾虑 | 命中 | 客户评审前一周我们催了两次签约，客户当场冷了 |
| 四 是否在标准上硬砸资源 | 信息不足 | 标书参数谁主导定的没摸清，需要您补一下 |
| 三 是否没弄清需求就讲方案 | 未见证据 | …… |
| 二 是否踩了政治地雷 | 信息不足 | 技术部态度没记录 |
| 一 这单当初该不该接 | 信息不足 | 等上面几项补完再回看 |

**健康度红绿灯**：🔴 红灯——评审前两周客户方承诺的工厂参观两次推迟均未兑现。（大白话：那时其实已经该警觉了。）

**最可能败因**：【五·施加购买压力】。
**教训清单**（请您确认后我再入档）：1. 客户推迟承诺动作两次即触发降级预期；2. ……
**落档回显**：确认后教训写入企业层记忆·我方资产，过程写入 客户分析\Q厂\交互记录.md。
```

*要点：倒序排查 + 每格三态判定；红绿灯补时间维度；教训清单必须经用户验证后才落档。*

## 示例 3：主权重夺（会话中段新客户插队，信号①）

**用户**（在决策链破译梳理 XX 集团决策链过程中）："对了，YY 厂也在招标，你看要不要跟？"

**Gateway 输出**：

```markdown
（先不抢当前话题）好的，YY 厂我记下了，先排队。

当前 XX 集团的决策链我们先梳理完——刚才说到副总分管范围还没摸清，继续。

YY 厂您是想现在并行评估，还是等 XX 这边告一段落再启动？
- 并行：我这边把 YY 厂按"商机初入"先建档占位，您随时把风声细节丢给我；
- 切换：我们重开一轮，先判 YY 厂的题。
```

*要点：新客户名 + 意图词出现 = 信号①，先答完当前再确认并行/切换，不抢话；确认切换才重走首轮流程。*

## 示例 4：纯对话兜底（无任何持久化通道）

**场景**：运行环境无文件写入工具、无记忆、无 CRM 连接器；阶段 skill 梳理完毕，进入收尾。

**Gateway 收尾输出（节选）**：

```markdown
本次梳理已完成。当前环境为纯对话模式，档案未落盘——以下是待存档文本块，请复制保存：

# ---- 待存档 · 客户分析\XX集团-某工厂\缺口与任务.md ----
（按 reference\12 模板逐文件输出，此处从略）

# ---- 待存档结束 ----
当前为纯对话模式，以上文本块未落盘；请复制保存到对应路径。
下次会话把文本块贴回，即视为有效读档来源。
```

*要点：首行路径注释保证贴回可解析；明示"未落盘"；环境恢复文件工具后下一轮自动落盘并回告。*
